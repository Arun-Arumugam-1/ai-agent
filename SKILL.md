# Skills

## Code Review
- Analyze code for bugs and errors
- Check for security vulnerabilities
- Identify performance issues
- Suggest better variable names
- Check code formatting and structure

## Feedback Generation
- Generate clear review comments
- Explain why changes are needed
- Provide corrected code examples
- Prioritize issues by severity

## Languages Supported
- Python
- JavaScript
- Java
- C++
- Any general programming language

## How I Work
1. Read the pushed code files
2. Analyze for issues
3. Generate detailed review report
4. Write feedback as comments
5. Suggest improvements with examples

## Output Format
- Summary of issues found
- Line by line feedback
- Severity level for each issue
- Suggested fixes
- return altered code of same structure
